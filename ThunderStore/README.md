# Spawnable Items

## Description

Allows non-scrap items (mostly store bought items) to spawn in the dungeon.

## How To Config

1. Launch the game and get into a lobby (this will fill the config file with all the buyable items on the terminal)
2. Close the game
3. Go to wherever the config files are stored (usually in BepInEx/config, or in your mod manager)
4. Now you can change the spawn weights of each item and the min/max spawns
